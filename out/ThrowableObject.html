Class: ThrowableObject

ThrowableObject(x, y, direction)

Represents a throwable object (e.g. a salsa bottle) in the game. Inherits movement and gravity from MovableObject.

Constructor

new ThrowableObject(x, y, direction)

Creates a new throwable object and starts the throw animation.
Parameters:
Name Type Description
x number Initial x position.
y number Initial y position.
direction boolean Direction of throw. `true` for left, `false` for right.
